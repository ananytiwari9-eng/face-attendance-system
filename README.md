# Face Attendance System

A face recognition based attendance management system built using:

- Python
- OpenCV
- Flask
- MySQL
- HTML/CSS

## Features

- Student management
- Face capture
- Face recognition
- Automatic attendance
- MySQL database
- Dashboard
- Attendance reports
- CSV report export
- Face model training

## Installation

Clone the repository:

git clone https://github.com/ananytiwari9-eng/face-attendance-system.git

Enter project folder:

cd face-attendance-system

Create virtual environment:

python -m venv venv

Activate it:

Windows:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Configure MySQL using .env.

Run:

python app.py
